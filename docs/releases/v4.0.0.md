## LivnTools v4.0.0

Format öncesi kurtarma, format sonrası kurulum ve günlük Windows bakımı için modüler v4 sürümü.

### Yenilikler
- Önizleme, işlem günlüğü ve önceki ayara dönüş sağlayan PowerShell/WPF motoru.
- 85 ayar tanımı, 45 temizlik/bakım işlemi, 40 uygulama ve 6 hazır seçim.
- Kurtarma kiti: sürücüler, uygulama listesi, Livn kopyası ve isteğe bağlı Wi-Fi/oyun kayıtları.
- Eksik kopya ve iptal durumlarını doğru raporlama; zorunlu uygulama dosyası denetimi.
- Windows PowerShell 5.1 için disk belleği geri alma doğrulaması ve ağ ölçüm geçmişi düzeltmeleri.
- IPv4/IPv6 DNS tercihlerinin ayrı saklanması ve geri yüklenmesi.
- Temizlik önizlemesi, kurulu uygulama envanteri ve taşınabilir seçim profili.
- Yenilenen README, kullanım rehberi ve sürüme sabit SHA-256 denetimli kurulum.

### Kurulum
`LivnTools-4.0.0.zip` dosyasını ayrı bir klasöre çıkarıp `LivnTools.bat` dosyasını çalıştırın. Uygulamayı açmak tek başına tweak uygulamaz.

```powershell
irm https://raw.githubusercontent.com/LiVNLOUD/livn-tools/v4.0.0/win.ps1 | iex
```

### Doğrulama
Windows PowerShell 5.1 testleri, statik analiz, WPF temel doğrulaması ve manifest kontrolü başarılı olmadan yayın akışı release'i yayımlamaz. Windows doğrulamasında 512 test geçti, 0 başarısız ve platforma bağlı 7 test atlandı; WPF, statik analiz ve manifest kontrolleri de geçti. Önceki Linux tabanında 518 test geçmişti. Gerçek Windows 10/11 donanımında bütün ayarların etkinliği, görsel/DPI kabulü, WinGet/sürücü işlemleri ve performans etkileri bu testlerin kapsamında değildir.

Kurtarma kiti disk imajı değildir. Temizlik, kurulum/kaldırma ve kullanıcı betikleri ayar geri alma sistemine dahil değildir. Üçüncü taraf güç planları ve ISLC standart ZIP'te yer almaz. Yeni bir lisans eklenmemiştir.

`SHA256SUMS.txt` ZIP bütünlük özetini içerir. Kaynak kod GitHub Source code arşivlerindedir.
